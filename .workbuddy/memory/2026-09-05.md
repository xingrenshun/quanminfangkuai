## 全民方块（QuanMingFangKuai）项目

### 激励视频修复（GuangGao.cs）

**问题**：抖音开发者工具内点击"看广告（+50 金币）"无反应，Console 反复打印 `[StarkVideoAd] video ad is showing` 但无任何 OnLoad / OnClose / OnError 回调，金币从未到账。

**根因**：原 `ShowReward` 同步执行 `Load(); Show();`，未等广告位就绪就 Show，SDK 状态置为 is showing 但素材没拉到；`OnError` 里又 `Show()` 形成死循环；`OnError` / `OnLoad` 无日志，无法排查。

**修复**：GuangGao.cs
- 新增 `rewardLoading` 字段防重入。
- `CreateReward`：注册 `OnLoad`（无参，Action）日志，广告加载完成后真正 `Show`；`OnClose` 用正确签名 `(bool isEnded, int count)`，仅 isEnded=true 时发放奖励；`OnError` 用正确签名 `(int code, string msg)`，只打日志，绝不再 `Show()`。
- `ShowReward`：改为异步流程——记录 action → `Load()`，由 `OnLoad` 回调触发 `Show()`，避免 SDK 内部 is showing 但素材未就绪的卡死。

**验证**：通过 dnfile 反编译 ttsdk.dll 的 Event 表 + NestedClass 映射，精确解出三个委托的 MethodDefSig：
- `AdLoadDelegate.Invoke`: `20 00 01` → `Action`（无参，void 返回）
- `RewardedAdClosedDelegate.Invoke`: `20 02 01 02 08` → `(bool, int)`
- `AdErrorDelegate.Invoke`: `20 02 01 08 0e` → `(int, string)`
